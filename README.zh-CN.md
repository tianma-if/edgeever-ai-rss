# EdgeEver AI RSS

[English](README.md)

这是 [EdgeEver](https://github.com/tianma-if/edgeever) 官方插件。

以 AI 为核心的 EdgeEver RSS / Atom 日报插件。它使用 EdgeEver 工作区已经配置的默认 AI Provider，将精选订阅按主题整理成日报并直接保存为笔记。

## 功能

- 首次默认启用包含 18 个来源的“AI 前沿”，覆盖官方实验室、每日简报、研究分析、实践者写作、中文机器学习与深度访谈；另提供开发与开源、中文阅读、科学与研究、产品与设计、商业与创业、安全与隐私等可选主题。
- 并发读取精选 RSS / Atom 并缓存最近文章；单个订阅源或 AI 请求失败不会阻止其他分类继续生成。跨来源事件聚类会折叠规范化链接、规范化标题及高置信度相似标题，同时保留全部佐证来源。
- 生成日报前按设置的目标语言批量翻译标题与摘要；已处理且原文未变化的结果会复用缓存，关闭自动翻译后不会产生这部分 AI 调用，单批翻译失败也不会阻断日报。
- 按所选主题分别生成 RSS 日报，默认汇总最近 24 小时，标题采用 `YYYY-MM-DD · 分类 · RSS 日报`；正文通常包含 7 至 10 个独立热点，以带序号的热点概括本身作为标题，每个热点包含简短要点和直接信源链接。候选不足时不会为凑数而重复或虚构热点。候选文章会按规范化链接和标题去重、覆盖当前可用的来源角色，并限制单一来源占比后再交给 AI。同日同分类再次生成时更新原笔记，没有新内容的分类会跳过。每个有内容的主题调用一次 AI。
- 可由用户明确开启桌面端自动日报，并按设备时区从 24 个整点中选择生成时间；默认关闭，界面会在启用前说明 AI 调用方式，也可随时暂停。
- 通过 EdgeEver 官方声明式插件设置页统一配置订阅主题、自动日报时间、日报时间范围和单分类文章上限；布局、校验、响应式与保存状态由 EdgeEver 统一提供。
- 不注册独立阅读页面；手动或自动生成的日报直接写入工作区笔记本，优先沿用已有目标笔记本，否则使用首个笔记本。
- Provider、模型和凭据完全由 EdgeEver 管理。

## 开发

```sh
bun install
bun run check
bun run check:feeds # 可选：在线检查内置订阅源健康状态
```

构建会生成 EdgeEver 所需的 `main.js` 与 `styles.css`。发布 GitHub Release 时，应将它们与仓库根目录的 `manifest.json` 一同上传，并确保版本与标签一致。

插件通过 EdgeEver 的匿名只读网络传输获取公开订阅，不携带 Cookie、账号凭据或敏感请求头。内置来源均经过验证；后续可增加对任意公开 HTTPS RSS / Atom 地址的支持。
